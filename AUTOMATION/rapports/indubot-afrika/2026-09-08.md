## Le défaut — [PR #3](https://github.com/dosteeve2-hash/indubot-afrika/pull/3)

`chart-stat-flow` formatait ainsi :

```ts
new Intl.NumberFormat(undefined, formatOptions).format(value)
```

`undefined` demande la locale de **l'environnement**. Le composant est `"use client"`
mais reste rendu côté serveur au premier passage. Mesuré ici : le serveur répond `en-US`
et rend `1,234`, un navigateur français rend `1 234`. Même entrée, deux textes pour le
même nœud — **divergence d'hydratation**.

Chaîne d'utilisation vérifiée : `chart-stat-flow` → `ring-center` →
`machines-ring-chart` → `/dashboard`. Le code est atteint.

Deux détails qui rendent le diagnostic sûr :
- **Le fichier évite déjà une autre divergence d'hydratation** deux fonctions plus bas,
  avec un commentaire qui l'explique. L'attention y était ; ce cas est passé au travers.
- **C'était le seul site fautif.** L'en-tête du tableau de bord et la politique de
  confidentialité épinglent `fr-FR`. Une incohérence isolée est un oubli, pas un choix.

## Ce que j'ai construit
- `src/lib/format-stat.ts`, locale épinglée. Le type y déménage, le composant le
  réexporte pour ne casser aucun import.
- Valeur non finie → « — » plutôt que « NaN ».
- **Le dépôt n'avait aucun test.** Il en a huit ; la CI passe de `lint+build` à
  `lint+tests+build`.

## Mes deux erreurs de la matinée, documentées dans le test

**J'ai inventé un type** au lieu de reprendre `ChartStatFlowFormat`. Le leur accepte
`style: 'currency'`, le mien non. `tsc` l'a rattrapé.

**Mes assertions contenaient des espaces ordinaires.** `fr-FR` utilise **deux espaces
invisibles différentes** : `U+202F` pour le groupement des milliers, `U+00A0` avant le
suffixe compact. Quatre tests ont échoué avec « expected `1,5 M` to be `1,5 M` » — deux
chaînes visuellement identiques. Les deux caractères sont maintenant nommés dans le
fichier plutôt que laissés invisibles.

C'est la deuxième fois en deux projets qu'un caractère invisible me coûte un aller-retour.
La règle vaut d'être retenue : **dans un test sur du texte localisé, nommer le séparateur.**
