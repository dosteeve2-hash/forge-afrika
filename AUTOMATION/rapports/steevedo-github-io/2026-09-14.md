## Le point qui compte vraiment

Même si on le remplissait, **ce dépôt ne servirait pas de site personnel**. GitHub Pages
n'attribue le site racine d'un compte qu'au dépôt nommé exactement
`<compte>.github.io`. Le compte est **`dosteeve2-hash`** : le dépôt racine devrait donc
s'appeler `dosteeve2-hash.github.io`.

Nommé `steevedo.github.io`, il ne peut être qu'un site de *projet*, servi à
`https://dosteeve2-hash.github.io/steevedo.github.io/` — une URL que personne ne
tapera. Le nom vient vraisemblablement d'un ancien pseudo.

Autrement dit, l'ambition inscrite au registre — « rediriger vers le portfolio 2.0 » —
n'est pas réalisable par ce dépôt tel qu'il est nommé.
