## 1. Le tronc ne se construit pas sans secrets

```
$ npm run build
✓ Compiled successfully in 9.7s
Error: Missing API key. Pass it to the constructor `new Resend("re_123")`
> Build error occurred
Error: Failed to collect page data for /api/onboarding
```

`src/lib/email.ts` construisait le client Resend **au chargement du module** :

```ts
const resend = new Resend((process.env.RESEND_API_KEY ?? '').replace(/^﻿/, ''))
```

`new Resend()` lève quand la clé manque. Next.js charge donc ce module pendant la collecte des
données de `/api/onboarding`, et le build s'arrête.

Conséquence : **aucune CI ne peut construire ce dépôt**, et aucun contributeur sans clé Resend de
production non plus. C'est le genre de défaut qui rend un projet impossible à reprendre.

| `npx vitest run` | 24 / 24 |
| `npm run build` | **ÉCHOUE** sans `RESEND_API_KEY` |

## 2. La PR #14 corrige tout — vérifiée

> *Répare 131 erreurs de lint, débloque le build sans secrets, ajoute la CI* — 2 septembre.

| | `main` seul | avec la #14 |
|---|---|---|
| `npx eslint .` | **131 erreurs** | **0 erreur**, 65 avertissements |
| `npx vitest run` | 24 / 24 | 24 / 24 |
| `npm run build` | **échoue** | **passe** — 38 pages |

Le correctif est exactement le bon geste — construire le client à l'appel plutôt qu'au
chargement :

```ts
function resendClient(): Resend {
  return new Resend((process.env.RESEND_API_KEY ?? '').replace(/^﻿/, ''))
}
```

**Recommandation : la fusionner.** Sans elle, rien ne peut vérifier ce dépôt.
