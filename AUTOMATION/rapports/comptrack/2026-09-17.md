## Leçon

La même qu'hier, sous une autre forme : **une fusion ne livre pas forcément**. Hier une PR empilée sur une branche de PR ; aujourd'hui une PR visant une branche qui ne va pas en production. Dans les deux cas GitHub affiche « merged » et rien n'atteint l'utilisateur. **Règle 29.**
