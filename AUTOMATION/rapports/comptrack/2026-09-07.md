## La seule PR qui compte

**[#38](https://github.com/dosteeve2-hash/comptrack/pull/38)** — 5 jours, base = le tronc,
n'ajoute aucune page. Elle répare ce qui bloque tout le reste :

- `npm run lint` partait en **questionnaire interactif** (« How would you like to configure
  ESLint? ») faute de fichier de configuration. En CI, ça reste bloqué jusqu'au délai
  d'expiration. C'est la raison pour laquelle ce dépôt n'a jamais eu de CI qui tienne.
- 6 tests sur 72 échouaient. Ils passent tous.
- Une CI est ajoutée : lint → test → build.

C'est la porte d'entrée. Tant qu'elle n'est pas franchie, rien ne peut être vérifié
automatiquement sur CompTrack.

## Ce que je n'ai pas fait, et pourquoi

**Je n'ai fermé aucune PR.** Dix-sept d'entre elles sont périmées selon mon analyse, mais
en fermer dix-sept d'un coup est une action irréversible qui appartient à Steeve. Et mon
analyse peut avoir un angle mort : une PR peut contenir, à côté d'une page périmée, une
migration SQL ou un utilitaire qui n'existe nulle part ailleurs.

**Je n'ai rien construit.** Ajouter une fonctionnalité à un dépôt qui a 20 PR en attente,
c'est en ajouter une vingt-et-unième.
