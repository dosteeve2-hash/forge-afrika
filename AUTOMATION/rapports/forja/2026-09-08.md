## 4. PR #1 à #9 — un produit que `master` n'est plus

Ce n'est pas un problème de rebase. C'est deux produits différents dans un seul dépôt.

**Ce que proposent les PR de juillet** — un domaine *export de café* :
`dashboard/lots`, `dashboard/exportations`, `dashboard/acheteurs`, `dashboard/finances`,
`dashboard/contrats`, `dashboard/parametres`, plus `/tarifs`, `/login`, `/a-propos`,
`/fonctionnalites`, un manifeste PWA, et les migrations `004_lots` → `008_finances`.

**Ce qu'est `master` aujourd'hui** — un ERP PME + tontine :
`(dashboard)/clients`, `commandes`, `devis`, `produits`, `qualite`, `planning`, `rapports`,
`statistiques`, `partenaires`, et une section `tontine/`. Une seule migration : `001_waitlist.sql`.

Trois incompatibilités concrètes :

1. **Deux arborescences.** Les PR écrivent dans `src/app/dashboard/`, le tronc dans
   `src/app/(dashboard)/` (groupe de routes). Fusionner produirait deux tableaux de bord, deux
   `layout.tsx`, deux barres latérales, dans la même application.
2. **Les migrations ne s'enchaînent pas.** Les PR sautent de `001` à `004` : les migrations
   `002` et `003` n'existent nulle part. La suite SQL est incomplète, elle ne se rejouerait pas.
3. **Convention périmée.** La #3 ajoute `src/middleware.ts` ; `master` est passé à `proxy.ts`
   le 10 août (convention Next.js 16). Les deux fichiers coexisteraient.

Elles sont aussi **imbriquées**, ce qui réduit la décision à trois PR au lieu de neuf :

- `#1 ⊂ #2 ≡ #3` — **#2 et #3 ont exactement le même HEAD** (`f3d513b`), seule leur base diffère
  (#2 vise `feat/pages-pwa`, #3 vise `master`). La #3 contient donc déjà tout #1 et #2.
  **La #2 est un doublon strict de la #3 et peut être fermée sans rien perdre.**
- `#4 ⊂ #5` (lots ⊂ lots+paramètres)
- `#6 ⊂ #7 ⊂ #8 ⊂ #9` (exportations ⊂ acheteurs ⊂ finances ⊂ contrats)

Ne survivent réellement que les pointes : **#3, #5, #9**. Les six autres (#1, #2, #4, #6, #7, #8)
sont des états intermédiaires de ces trois-là.

**Je ne ferme rien ici.** La question n'est pas technique, elle est produit : *FORJA fait-il encore
de l'export de café ?* Si oui, ce travail se réécrit sur l'arborescence actuelle, il ne se fusionne
pas. Si non, les neuf PR se ferment d'un bloc. Question posée à Steeve (Q10), hypothèse retenue en
attendant : **le tronc a raison, l'export de café a été abandonné en août** — et donc aucune de ces
neuf PR ne sera fusionnée en l'état.
