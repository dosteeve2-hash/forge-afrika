# FORGE Afrika

Logiciels pour les filières africaines : agriculture, élevage, transformation, comptabilité et commerce.
Projet en phase pilote, fondé par **Steeve Donald Compaoré**. Site : https://forge-afrika.vercel.app

## Ce que c'est

FORGE Afrika développe des outils simples, pensés pour le terrain et la connexion instable. Chaque outil traite un maillon précis d'une filière et peut s'utiliser seul. Le projet démarre : nous cherchons nos premiers partenaires pilotes.

"Disponible (pilote)" veut dire en ligne et utilisable, mais encore en cours d'amélioration. Aucun chiffre d'utilisation n'est affiché : il n'y a pas encore d'utilisateurs établis.

## Ce dépôt

Le site vitrine (Next.js, TypeScript, Tailwind CSS), plus la vision et la feuille de route (`VISION.md`, `ROADMAP.md`, `PROJECT.md`). Les documents de vision décrivent des objectifs, pas des résultats.

```
npm install
npm run dev
```

Déploiement : `vercel deploy --prod --yes` (le compte Vercel n'est pas lié à GitHub).
